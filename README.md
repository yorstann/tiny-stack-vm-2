# Tiny Stack VM

A tiny stack virtual machine for make.fun's tiny-stack-vm-01 bounty, written in TypeScript for Node 22. One run of `main.ts` answers all 40 instances: it reads each program's `program.bin` and `input.bin`, executes the 37-opcode ISA over wrapping 32-bit integers — a 256-value data stack, a 64-deep call stack, 256 words of memory, signed 16-bit relative jumps and absolute calls — and writes `stdout.bin` plus `exit.txt` for every instance. The interpreter is table-driven: each opcode maps to its immediate size and stack effect, checked before execution, then a single switch implements every operation with exact trap semantics (all ten trap codes, the 1,000,000-step limit and the 65,536-byte output limit), including the edge cases the ISA warns about: wrapping multiplication, `INT_MIN / -1`, unsigned division and comparisons, shift counts masked to five bits, sign-extended `PUSH8`, and `EXIT`'s low byte. The whole repository fits the 8,192-byte cap.
